# 0.10.0

spatiomic is now licensed under the Apache License, version 2.0. Versions before 0.10.0 were released under the GNU General Public License, version 3.

## Highlights

- **Faster self-organizing maps.** `so.dimension.som` now trains Kohonen's batch SOM with [fastersom](https://github.com/dschaub95/fastersom) by Darius Schaub, in PyTorch on CUDA, Apple MPS or the CPU. Fitting is much faster, especially on the CPU and with the cosine metric, and all four distance metrics (`euclidean`, `manhattan`, `cosine`, `correlation`) work without a custom XPySom fork.
- **No GPL dependencies.** `python-igraph` is replaced by networkx on the CPU and cuGraph on the GPU, which made the switch to Apache-2.0 possible.
- **Seurat-style shared nearest neighbor graphs.** `so.neighbor.snn_graph` builds Jaccard-weighted SNN graphs as in Seurat and PhenoGraph, in seconds for tens of thousands of data points.

## Breaking changes

### Self-organizing maps (`so.dimension.som`)

- A batch SOM has no learning rate and always uses a gaussian neighborhood: `learning_rate_initial`, `learning_rate_final`, `neighborhood`, `neighborhood_accuracy`, `parallel_count` and `n_jobs` were removed. New constructor arguments are `initialization` (`"random"`, `"sample"` or `"pca"`) and `batch_size`.
- `fit(..., pca_init=True)` is replaced by `som(..., initialization="pca")`.
- `sigma_initial` and `sigma_final` are floats on fastersom's scale. The defaults (`None`) reproduce the maps of the previous version.
- `predict` returns arrays of shape `(n,)` instead of `(n, 1)`. With `return_distance=True` the order is unchanged: `(distances, node_ids)`.
- Data points without a nearest node (all-zero data points with the cosine metric, constant data points with the correlation metric) get node id `-1`, distance NaN and label `-1`, and are excluded from the quantization error. Before, they were assigned to node 0. `label` returns `int32` instead of `uint16` so that `-1` fits.
- The `som.som` (XPySom object), `set_estimators()` and `neighbor_estimator` attributes were removed. Use `som.get_distance_map()` for the U-matrix.
- `use_gpu=True` also uses Apple MPS when available.
- Maps saved by previous versions load if `xpysom==1.0.7` is installed; save them again to drop the dependency.

### Graphs and clustering

- `so.neighbor.knn_graph.create` returns an undirected `networkx.Graph` with one integer node per data point, in the order of the flattened data, instead of an `igraph.Graph`.
- `so.neighbor.snn_graph.create` takes the data (or a fitted SOM) and a `neighbor_count` instead of a k-nearest neighbor graph. Edges carry the Jaccard index of the neighborhoods as `weight`, and edges with a weight of at most `prune_threshold` (default 1/15) are removed. `shared_count_threshold`, `fix_lonely_nodes`, `fix_lonely_nodes_method` and `distance_data` were replaced by `connect_isolated_nodes`, which keeps the strongest edge of data points that would otherwise have none.
- `so.cluster.leiden` uses `networkx.community.leiden_communities` on the CPU and respects edge weights. `iteration_count` now caps the number of levels (CPU) or iterations (GPU) and defaults to `None`, which runs until the modularity no longer improves. Communities are not bit-identical to the igraph-based results of previous versions.
- `so.plot.connectivity_graph` takes a `networkx.Graph`.

### Installation

- Python 3.12 or later is required; Python 3.12 to 3.14 are tested.
- PyTorch is a required dependency (through fastersom).
- The `cuda-11` extra was replaced by `cuda-13`, as RAPIDS no longer supports CUDA 11. The `cuda-12` and `cuda-13` extras require RAPIDS 25.10 or later.
- The `cellpose` extra requires Cellpose 4.2 or later, and `so.segment.cellpose` defaults to the updated CellposeSAM model `cpsam_v2`, which predicts fewer spurious masks in low-contrast regions. The DINOv3-based models `cpdino` and `cpdino-vitb` are available through `pretrained_model`; pass `pretrained_model="cpsam"` for the previous default.
- The `pysal` metapackage was replaced by `libpysal` and `esda`, which removes about 15 unused geospatial packages from installations.

## Bug fixes

- `so.data.read.read_czi` no longer casts all images to `uint8`, which truncated 16-bit images, and reads CZI files independent of their dimension layout.
- `so.process.clip` with `method="minmax"` no longer ignores `fill_value=0.0` and accepts per-channel fill values.
- Methods decorated to accept AnnData objects work with NumPy 2.4 and later.
- `so.spatial.vicinity_composition` and `so.spatial.vicinity_graph` work with pandas 3, and `vicinity_graph` no longer modifies the input data frame.

## Development

- Development dependencies are split into the `test`, `lint` and `doc` groups, which the `dev` group includes.
- The CI tests Python 3.12 to 3.14 (the Python version matrix previously had no effect) and installs from the lock file.
