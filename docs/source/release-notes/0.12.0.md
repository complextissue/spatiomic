# 0.12.0

## New features

- **Mutual k-nearest neighbor graphs.** `so.neighbor.mnn_graph.create` takes the data (or a fitted SOM) and a `neighbor_count` and connects two data points only if each is among the `neighbor_count` nearest neighbors of the other. Unlike in a k-nearest neighbor graph, small groups of data points far from the rest of the data are not connected to it. With `connect_isolated_nodes=True` (the default), data points without mutual neighbors keep the edge to their nearest neighbor. The graph is unweighted, like the graph of `so.neighbor.knn_graph`, and works with `so.cluster.leiden`.

## Dependencies

- fastersom 0.5.0 is required, which finds the best-matching units of `so.dimension.som` on Apple GPUs (MPS) with fused Metal kernels.
